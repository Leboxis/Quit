# V4 · V5 · V6 — SOS personnalisé, habitudes concrètes, parcours contextualisé

Statut : implémenté sur `feature/v4-v5-v6`, validation native via CI.

## V4 — SOS personnalisé
- Favoris (max 3), plan SOS personnel (durée + 1-3 gestes), marquage « utile ».
- Ordre : favoris → utiles explicites → prouvées auto (count ≥ 3, réduction > 0) → défauts. Voir `AppStore.suggestions(for:)`.
- Raccourci : carte SOS dans `TodayView` (`today.sos`) + barre existante. Timer recalculé au retour (`scenePhase`).
- Suivi avant/après conservé dans `UrgeSession` et affiché dans `doneStep`.

## V5 — Comprendre ses habitudes
- `ProgressSnapshot` : déclencheurs triés, top 3 créneaux sensibles, médiane + moyenne retour plan, flag `insufficientData`.
- `InsightsView` : carte moments sensibles, déclencheurs fréquents, états « Peu de données », historique avec moyenne + médiane.
- Wording non prédictif : « semble », « associations », jamais « risque/prédit ».

## V6 — Parcours contextualisé
- `JourneyCatalog.recommendation(for:)` : règle locale transparente (épisode récent → Après un écart ; scrolling/ennui → Traverser ; lit → Environnement ; sinon Fondamentaux).
- Entrée « Pour toi » dans `JourneyView` + lien depuis `EpisodeView` après enregistrement.
- Rythme (`Pace` : libre/quotidien/hebdo), bilan hebdo (`WeeklyReviewView`), maintenance après 42/42 avec « Reprendre en douceur ».
- Mêmes 42 IDs, compat V1/V2/V3 préservée (champs optionnels, `decodeIfPresent`).
